# Global Electronics Retail Analysis

A data analytics portfolio project focused on analyzing retail sales, customers, products, stores, and business performance using **SQL and Power BI**.

## Project Overview

This project analyzes the Global Electronics Retail dataset to identify business trends, customer behavior, product performance, and store efficiency.

* MySQL
* Power BI
* DAX
