# Power BI Analysis

Interactive Power BI dashboard for the Global Electronics Retail Analysis project.

## Dashboard Pages

* Executive Dashboard
* Customer Analysis
* Product Analysis
* Geography & Store Analysis

## Key Analysis

* Sales performance and monthly trends
* Customer and country analysis
* Product category and product performance
* Store performance and sales efficiency
* Sales per square meter analysis

## Tools Used

* Power BI
* MySQL
* DAX
